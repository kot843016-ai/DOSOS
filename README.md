# DOSOS

**DOSOS** is an experimental 16-bit operating system for x86 computers, written in FASM (Flat Assembler).

The project aims to create a lightweight, independent operating system with a DOS-like interface, its own executable format and basic file management capabilities.

## Features

- 16-bit x86 real-mode architecture
- Written in FASM assembly language
- FAT12 filesystem support
- Custom DX16 executable format
- Command-line interface
- Basic file operations
- Program execution
- System API via software interrupts

## Project Status

**Stage:** 6  
**Status:** Experimental / Early Development

DOSOS is actively developed. Features and interfaces may change.

## Requirements

- x86-compatible computer or emulator
- FASM assembler
- FAT12 bootable disk image
